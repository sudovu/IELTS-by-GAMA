## 2. Documented Technical & Operational Boundaries

### 1. Formative Practice Status (Not an Official IELTS Result)
- **Status:** IELTS by GAMA is an independent training application.
- **Accreditation Disclaimer:** The software is **not** endorsed by, accredited by, or affiliated with Cambridge Assessment English, IDP: IELTS Australia, or the British Council.
- **Score Utility:** Bands generated by the evaluation engine are diagnostic practice estimates ($\pm 0.5$ band margin of error). They cannot be submitted to immigration departments, universities, or licensing boards as certified language test results.

### 2. Speech Evaluation Modality (Non-Acoustic Transcript Recognition)
- **Technology:** Speaking practice evaluates candidate responses using speech-to-text transcript recognition, text-based grammar analysis, lexical diversity counters, and fluency tracker pacing.
- **Acoustic Boundary:** The application does **not** conduct acoustic spectral, formant, or phonemic pitch analysis.
- **Pronunciation Rating:** Pronunciation scores represent a neutral baseline and are unassessed via acoustic analysis. Students are explicitly informed of this limitation directly on the speaking evaluation card.

### 3. Speech Synthesis Audio Content
- **Delivery:** Listening section audio is rendered using native speech synthesis playback of authentic IELTS dialogue scripts rather than bundled multi-voice studio recordings.
- **Student Impact:** All questions, distractor patterns, accents, and information densities accurately reflect IELTS standards. The full transcript is accessible for reading and review.

### 4. Client-Side Web Deployment vs Server Mode
- **GitHub Pages Deployment:** When accessed directly on `https://gautambhuwan.com.np/ielts/`, the application runs completely client-side in the student's browser using `OfflineLocalEngine` and `localStorage`.
- **Multi-Device Sync:** Progress in client-side mode is saved locally to that specific device/browser. Power users who desire cross-device synchronized SQLite storage can host or run the Python backend (`ui/server.py`) on a local machine or private server.
