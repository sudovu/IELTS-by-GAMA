## 1. Writing Assessment Validation

### 1.1 Criteria Scoring & Dual-Task Weighting
The Writing evaluation engine (`WritingEvaluator`) grades essays across all four official criteria:
1. **Task Achievement / Task Response (25%)**: Overview presence, trend analysis, letter conventions, position clarity.
2. **Coherence & Cohesion (25%)**: Paragraph division, logical progression, cohesive device range and accuracy.
3. **Lexical Resource (25%)**: Vocabulary range, academic collocations, spelling accuracy.
4. **Grammatical Range & Accuracy (25%)**: Complex sentence structures, error density, passive voice, punctuation.

**Dual-Task Weighting Formula:**
Official Cambridge IELTS rules dictate that Task 2 carries **twice the weight** of Task 1:
$$\text{Writing Band} = \text{round\_band}\left(\frac{1}{3} \times \text{Task 1} + \frac{2}{3} \times \text{Task 2}\right)$$
*Example:* Task 1 Band 6.0 and Task 2 Band 7.0 yields:
$$\frac{6.0}{3} + \frac{14.0}{3} = \frac{20.0}{3} = 6.67 \longrightarrow \text{Band 6.5}$$
*Example:* Task 1 Band 7.0 and Task 2 Band 6.0 yields:
$$\frac{7.0}{3} + \frac{12.0}{3} = \frac{19.0}{3} = 6.33 \longrightarrow \text{Band 6.5}$$
The rounding algorithm `BandCalculator.round_band()` rounds to the nearest half-band (ending in `.0` or `.5`), exactly matching official British Council and IDP calculation rules.

### 1.2 Resolution of Zero-Word Scoring Defect
- **Audit Finding:** Previously, an empty string (`""` or 0 words) was awarded **Band 5.0** because criteria scores were clamped to minimum 4.0 or 5.0.
- **Correction:** Implemented strict non-response and underlength guards:
  - **0 words (Unanswered):** Immediately returns **Band 0.0** across all 4 criteria with feedback: *"No response submitted. In IELTS, unanswered writing tasks receive Band 0.0."*
  - **$<25$ words:** Returns **Band 1.5** with diagnostic feedback noting severe underlength.
  - **$<50$ words:** Underlength penalty applied; capped at Band 3.0.

### 1.3 Disclosure Regarding $\pm 0.5$ "Confidence Interval"
- **Finding:** Phase 14 labeled the score range as a "$\pm 0.5$ confidence interval".
- **Clarification:** A true statistical confidence interval requires empirical calibration against a benchmark dataset of double-marked human IELTS candidate scripts. Because this engine uses deterministic heuristic rubrics without a calibrated human script dataset, the $\pm 0.5$ span is an **internal heuristic estimate range**, not a statistical confidence interval. All scorecards have been updated to describe it as an *Estimate Range*.

## 2. Speaking Assessment Validation

### 2.1 Modality Disclosure & Non-Acoustic Limitations
- **Current Modality:** The speaking examiner processes **text transcripts** generated by browser Speech-to-Text (Web Speech API) or direct text input.
- **Non-Acoustic Limitation:** The system analyzes word choices, grammatical complexity, fluency metrics (words per minute, filler density), and response length. It **does NOT analyze acoustic phonetics, vocal formant resonance, pitch variation, stress, or intonation**.
- **Transparency:** The platform explicitly discloses:  
  *"Evaluated via transcript heuristics (non-acoustic). Acoustic pronunciation, stress, and intonation are not analyzed."*

### 2.2 Resolution of Zero-Word Speaking Defect
- **Audit Finding:** A completely silent or empty speaking turn previously received **Band 6.5** because zero grammatical errors were detected and default fluency metrics were applied.
- **Correction:**
  - `FluencyTracker.analyze_fluency()` now returns **0.0 WPM and Band 0.0** when `word_count == 0`.
  - `SpeakingExaminer.evaluate_spoken_response()` immediately returns **Band 0.0** with criteria scores `FC=0, LR=0, GRA=0, P=0` when `word_count == 0`.
  - Responses under 10 words receive **Band 1.5** with advice to elaborate.

### 2.3 Preparation & Turn Timers
- **Part 1:** Direct response recording with conversational pacing guidance.
- **Part 2:** Long-turn cue card with an interactive **60-second preparation countdown timer**, followed by a **2-minute response timer**.
- **Part 3:** Two-way abstract discussion with analytical concession prompts.
